
create DB & User in Aiven.

Then connect to new db using quick connect using aiven admin db creds.

Give new user ownership to new db as below.

ALTER DATABASE "security-db" OWNER TO "security-user";
ALTER DATABASE "event-db" OWNER TO "event-user";
ALTER DATABASE "payment-db" OWNER TO "payment-user";
ALTER DATABASE "customer-db" OWNER TO "customer-user";
ALTER DATABASE "saga-db" OWNER TO "saga-user";

pg_dump -h pg-11835880-project-enigma.e.aivencloud.com -p 13359 -U payment-user -d payment-db --schema-only --no-owner --no-privileges -f payment-schema.sql


To connect to local postgreSQL running in a docker container:
=============================================================

docker run --name payment-postgres-test -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=payment-db-test -p 55432:5432 -d postgres:18

psql -h localhost -p 55432 -U postgres -d payment-db-test

==================================
pg_dump -h pg-11835880-project-enigma.e.aivencloud.com -p 13359 -U payment-user -d payment-db --schema-only --no-owner --no-privileges -f payment-schema.sql
