Tool		| Responsibility
----------------------------------------------------------------------------------------
Kind		| Run your local Kubernetes cluster
Skaffold	| Build Docker images and make them available to your Kind cluster
kubectl		| Create/update Deployments, Services, ConfigMaps, Secrets, namespaces, etc.




Kubernates Notes:
=================

starting docker nodes for kind cluster nodes:
---------------------------------------------
docker start laughing-enigma-control-plane laughing-enigma-worker
kubectl get nodes --context kind-laughing-enigma

checking the kubernates status:
-------------------------------
kubectl config current-context
kubectl get nodes
kubectl get pods -A

kubectl get namespaces
kubectl get pods --namespace laughing-enigma



stopping docker nodes for kind cluster nodes:
---------------------------------------------
docker stop laughing-enigma-control-plane laughing-enigma-worker
kubectl get nodes --context kind-laughing-enigma

Kind Cluster Notes:
===================
kind get clusters

To Start empty Kind Cluster for testing kind:
---------------------------------------------
kind create cluster --name laughing-enigma --wait 5m
kind create cluster --name laughing-enigma-test --retain --wait 5m

To start cluster using kind with kind config file:
--------------------------------------------------
kind create cluster --config k8s/cluster/kind-config.yaml
kind create cluster --config k8s/cluster/kind-config.yaml --verbosity 4
kind create cluster --config k8s/cluster/kind-config.yaml --verbosity 4 --retain



docker inspect laughing-enigma-control-plane
